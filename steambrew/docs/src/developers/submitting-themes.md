# Submitting Themes

Simply create a new issue on the
[Millennium](https://github.com/SteamClientHomebrew/Millennium/issues)
repository with the information about your theme attached.

This is done only once - unlike plugins, which require submitting a pull request
for new versions, themes will automatically update whenever you make a commit.

If your theme is approved, it will appear on https://steambrew.app/themes. The
website will automatically render your repository's README and other relevant
data from your `skin.json`.
